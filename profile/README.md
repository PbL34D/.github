# L34D Software

Independent Windows software for media, desktop productivity, local AI, and PC gaming. We also build developer tools and browser projects.

[Project catalog](https://l34d.ca/) · [Downloads](https://auth.l34d.ca/account/licenses) · [Release notes](https://updates.l34d.ca/) · [Manuals](https://docs.l34d.ca/) · [Support](https://support.l34d.ca/) · [GitHub repositories](https://github.com/orgs/PbL34D/repositories?type=public)

Sign in with an L34D account to download Windows installers and portable builds where offered.

## Apps and desktop tools

| Project | What it does |
| --- | --- |
| [AIMEE](https://aimee.l34d.ca/) | Organize photos and videos, edit clips, and play media across your screens. |
| [AIMEE Companion](https://l34d.ca/companion) | Browse your AIMEE Library from a phone, Steam Deck, or another PC. |
| [L34D Image Viewer](https://image.l34d.ca/) | Browse photos and compare images side by side. |
| [L34D Lab](https://lab.l34d.ca/) | A Windows toolkit for files, screenshots, writing, and desktop shortcuts. |
| [Desktop Droid](https://droid.l34d.ca/) | Play with an interactive desktop companion that has games and a world to explore. |
| [AliceXE](https://alicexe.l34d.ca/) | Chat, write, and research with local AI models on Windows. |
| [AWPtimizr](https://awptimizr.l34d.ca/) | Review Windows and gaming settings, measure performance, and undo supported changes. |
| [DemoVault](https://demovault.l34d.ca/) | Review Counter-Strike 2 demos, find highlights, and make clips. |
| [Diffraction](https://diffraction.l34d.ca/) | Replay Git history and visualize live file changes, DevTools events, and remote site traffic. |
| [R2Revival](https://r2revival.l34d.ca/) | Control a Hasbro Smart R2-D2 B7493 from Windows or Android. |
| [L34D DevTools](https://devtools.l34d.ca/) | Run local builds and tests, package applications, and manage releases. |
