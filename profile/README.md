# L34D Software

Independent Windows software for media, desktop productivity, local AI, and PC gaming.

[Website](https://l34d.ca/) · [Manuals and setup guides](https://docs.l34d.ca/) · [Release notes](https://updates.l34d.ca/) · [Support](https://support.l34d.ca/)

## Apps and guides

| Project | What it does |
| --- | --- |
| [AIMEE](https://aimee.l34d.ca/) | Organize photos and videos, edit clips, and play media across your screens. |
| [AIMEE Companion](https://l34d.ca/companion) | Browse your AIMEE Library from a phone, Steam Deck, or another PC. |
| [L34D Image Viewer](https://image.l34d.ca/) | Browse photos and compare images side by side. |
| [Desktop Droid](https://droid.l34d.ca/) | Play with an interactive desktop companion that has games and a world to explore. |
| [L34D Lab](https://lab.l34d.ca/) | A Windows toolkit for files, screenshots, writing, and desktop shortcuts. |
| [AliceXE](https://alicexe.l34d.ca/) | Chat, write, and research with local AI models on Windows. |
| [Diffraction](https://diffraction.l34d.ca/) | Visualize Git history, file changes, and application activity in your workspace. |
| [R2Revival](https://r2revival.l34d.ca/) | Control a Hasbro Smart R2-D2 B7493 from Windows or Android. |
| [AWPtimizr](https://awptimizr.l34d.ca/) | Review Windows and gaming settings, measure performance, and undo supported changes. |
| [DemoVault](https://demovault.l34d.ca/) | Review Counter-Strike 2 demos, find highlights, and make clips. |
| [Crosshair Lab](https://x.l34d.ca/) | Recover, convert, and build Counter-Strike 2 crosshairs in your browser. |
| [PC Optimizations](https://pc.l34d.ca/) | Practical guides for Windows 11, graphics drivers, game performance, and Steam security. |

## Tools in L34D Lab

- **Files and media:** [Rename](https://lab.l34d.ca/rename), [Resize](https://lab.l34d.ca/resize), [Compress Image/Video](https://lab.l34d.ca/compress-media), [Transit Copy](https://lab.l34d.ca/transit), [Relay Sync](https://lab.l34d.ca/relay), [FileSpawn](https://lab.l34d.ca/filespawn), [PowerShell Here](https://lab.l34d.ca/powershell-here), and [AIMEE Explorer Actions](https://lab.l34d.ca/aimee-actions).
- **Desktop:** [Deskchemy](https://lab.l34d.ca/wallpaper), [Cursor Lock](https://lab.l34d.ca/cursor-lock), [Desktop Control](https://lab.l34d.ca/desktop-control), [Orbit Window Manager](https://lab.l34d.ca/orbit), [Pin Window](https://lab.l34d.ca/pin-window), and [Paste History](https://lab.l34d.ca/advanced-paste).
- **Capture:** [Snaplet](https://lab.l34d.ca/snaplet), [Screen Measure](https://lab.l34d.ca/screen-measure), [Color Picker](https://lab.l34d.ca/color-picker), and [Text Extractor](https://lab.l34d.ca/text-extractor).
- **Writing:** [Talk2Text](https://lab.l34d.ca/talk2text) and [Proofread](https://lab.l34d.ca/proofread).

Use the [L34D Lab manual](https://lab.l34d.ca/user-manual) for setup and shortcuts, or [search L34D](https://l34d.ca/search) to find a project, manual, release, or support page.
